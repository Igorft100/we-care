## :house: Sobre o Projeto

<p align="justify">
O <strong>We Care</strong> representa a evolução de um projeto anterior, desenvolvido como o segundo desafio prático de CSS do DevClub. A proposta é apresentar uma landing page moderna voltada ao cuidado de pets, explorando conceitos de layout, hierarquia visual e responsividade para diferentes dispositivos.
</p>

<p align="justify">
O projeto reforça conceitos de adaptação para diferentes dispositivos, organização de layout e criação de interfaces voltadas ao cuidado e bem-estar de pets.
</p>

Funcionalidades:
- Layout adaptado para mobile e desktop
- Uso de boas práticas de CSS
- Organização visual e hierarquia de elementos
- Interface amigável e intuitiva
